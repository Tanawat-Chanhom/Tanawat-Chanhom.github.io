A status page hosted on the same infrastructure it reports on is not a status
page. Signal was built on the opposite assumption.

## Design constraint

Zero shared dependencies with production. Different provider, different DNS,
different deploy pipeline.

## Approach

A static page regenerated by an external watcher, with incident history in
version control so the timeline is auditable and every update is a reviewable
diff.

## Result

Signal stayed up through two full production outages, including one that took
the primary cloud region offline.

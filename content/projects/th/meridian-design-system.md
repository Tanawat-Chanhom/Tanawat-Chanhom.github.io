สี่ทีม ปุ่มสี่แบบ focus style สี่แบบ Meridian คือความพยายามที่จะหยุดเรื่องนี้

## ขอบเขต

Token pipeline ที่ผลิต CSS custom properties ออกมา, component library ที่สร้างทับ
บนนั้น และ Storybook เป็นพื้นที่กลางให้ดีไซน์กับวิศวกรรมรีวิวงานร่วมกัน

## สิ่งที่สำคัญที่สุด

การถูกนำไปใช้จริง design system ที่ไม่มีใครใช้ก็เป็นแค่โค้ดเบสที่สองให้ต้องดูแล
เส้นทางการย้ายจึงต้องทำทีละส่วนได้ ทีมค่อยๆ ย้ายทีละคอมโพเนนต์โดยไม่ต้องรื้อทีเดียวทั้งหมด

## ผลลัพธ์

สามในสี่ทีมย้ายครบภายในสองไตรมาส และจำนวนปัญหาด้าน accessibility ที่รายงานเข้ามา
กับคอมโพเนนต์กลางลดลงจนเกือบเป็นศูนย์
